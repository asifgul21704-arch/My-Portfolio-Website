## Run locally

### 1. Clone the repository

```bash
git clone https://github.com/asifgul21704-arch/My-Portfolio-Website.git
cd My-Portfolio-Website
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

If the repository contains an `.env.example`, copy it to `.env` and fill in the required values locally.

**Windows PowerShell:**

```powershell
Copy-Item .env.example .env
```

Keep SMTP credentials and all private keys on the server. Never commit a real `.env` file or expose secrets through `VITE_*` variables.

### 4. Start development

```bash
npm run dev
```

### 5. Check and build

```bash
npm run lint
npm run build
npm start
```

The scripts above are taken from the current package configuration. Run them locally to verify the current environment and build status.
